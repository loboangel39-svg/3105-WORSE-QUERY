# VINI 2.0 RC5 — UI changes

- Installed cards now expose textual `APPLY`, `RESTORE` or `PROCESANDO` actions with a larger touch area.
- Existing receipt state determines the action; no parallel operation engine was added.
- The detail navigation remains available but no longer presents a required arrow/action path for normal operations.
- The `Parches` section header was removed.
- The import `+` remains in the existing navigation toolbar rather than a separate row.
- Only the `Parche · .3105` badge and rule/workspace count text were removed from cards.
- Package name, primary icon, author, colors, card styling and internal metadata remain intact.
- Success alerts remain suppressed; real errors remain visible.
