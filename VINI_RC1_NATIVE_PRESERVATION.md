# VINI 2.0 RC1 — Native Preservation

Preserved without modification: `WQFiles`, bad_query/worse_query, access coordinators, container identity, entitlements, App Group, bundle ID, `PatchPackageCodec`, `PatchTransaction`, `VINIDualBackupStore`, and original Files/library views.

The remote cache is separate from A/B backup data. No automatic deletion of native packages or backup journals was introduced. Physical Apply/Restore and Files access require an iPhone validation run and remain pending here.
