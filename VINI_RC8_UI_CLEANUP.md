# VINI 2.0 RC8 — UI cleanup

- Removed the Installed toolbar `+` and its toolbar row; the first package row now follows the tabs directly.
- Removed the ordinary card `NavigationLink`, so tapping a package name/card no longer opens technical inspection.
- Preserved the existing locked-package action and the exceptional `REVISAR` recovery sheet.
- Preserved package icon, name, colors, card layout, two-line names and APPLY/RESTORE/PROCESANDO/REVISAR controls.
- Import, codec, library and synchronization code remain available internally and were not changed.
